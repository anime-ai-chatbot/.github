2. **Routing Layer.** The system analyzes the prompt to determine emotional weight and intent.
3. **Model Selection.** The prompt is routed to fine-tuned open-source models designed specifically for creative roleplay and NSFW content.
4. **Response Generation.** The model generates the initial response, focusing on pacing and descriptive language.
5. **Context and Memory Injection.** The system injects previous context so the AI remembers the established boundaries, kinks, and narrative history.
6. **Final Output.** The generated text is delivered to you, seamlessly continuing the fantasy.
